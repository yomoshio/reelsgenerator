# reelsmith

Делает вертикальные ролики из одной строки-идеи. Пишет сценарий, озвучивает его, рисует
кадры, оживляет их, кладёт музыку и субтитры. Готовый ролик ждёт, пока человек его
посмотрит и одобрит. Всё работает на своих моделях, без облачных API: интернет нужен
только чтобы один раз скачать веса.

Пример идеи: `Часть 1. Ночная смена в затопленном метро`. Из неё выходит ролик на минуту
с лишним в стиле серии с правилами выживания: плоская графика, диктор, плашки с
правилами, субтитры с выделенными словами.

## Как это устроено

```
идея → сценарий → голос → кадры → клипы → музыка → сборка → вы одобряете → outbox/
       Qwen3.5    VoxCPM2  Z-Image  Wan 2.2  ACE-Step  ffmpeg
```

После кадров, клипов и сборки ролик смотрит судья, та же Qwen3.5, но по картинкам.
Плохой клип переделывается сам. Как писать и как выглядеть, задаёт стиль, файл в
`styles/`. Каждый вызов модели записывается с ценой, поэтому видно, сколько стоит
годный ролик.

## Что нужно

- Видеокарта NVIDIA от 24 ГБ; удобно от 32 ГБ.
- 64 ГБ оперативной памяти и 250 ГБ на диске.
- Linux или Windows с WSL2, Docker с доступом к видеокарте.

## Запуск

```
make setup          # .env и папки
make build
make models         # около 90 ГБ весов
make llm-model
make voice DESC="A calm middle-aged man with a low warm voice"
make up
make migrate
```

Дальше каждый день:

```
make add IDEA="Часть 2. Артём находит второй блокнот"
make jobs                     # статусы и id
make review ID=<id>           # ролик в review/
make approve ID=<id>          # готовый ролик в outbox/
```

ComfyUI открывается на http://localhost:8188: там видно, как рисуются кадры и клипы,
и там же можно генерировать руками. `make help` показывает все команды.

## Разработка

Нужны Python 3.12 и ffmpeg, видеокарта не нужна.

```
python3.12 -m venv .venv && . .venv/bin/activate && pip install -e ".[dev]"
make test lint
make demo           # весь конвейер на заглушках
```

Код в `src/reelsmith/`, сервис голоса в `services/tts/`, скрипты в `scripts/`.
