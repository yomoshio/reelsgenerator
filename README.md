# reelsmith

Делает вертикальные ролики из идеи, рассказа или куска книги. Всё делают свои открытые
модели, без облачных API:
- языковая модель пишет историю целиком, режиссирует каждый бит и пишет код, который его
  рисует;
- модель со зрением проверяет кадры;
- Chatterbox озвучивает голосом диктора (или Qwen3-TTS, по настройке);
- рисует код: плоская векторная графика, кукла героя на шарнирах, плашки на словах диктора.

Поэтому картинка плавная, герой одинаковый в каждом кадре, а вещи стоят на своих местах.

```
идея → план → биты → кастинг → режиссура → голос → код сцен → кадры → сборка → вы одобряете
       qwen   qwen    qwen       qwen      Qwen3-TTS  кодер      Node     ffmpeg
                                           whisper    + зрение
```

Модели работают на видеокарте: своей или арендованной. Отрисовка и сборка идут на
процессоре.

## Что нужно

- Для конвейера: Linux, macOS или Windows (через WSL2), Python 3.12, Node 22, ffmpeg.
  Видеокарта не нужна.
- Для моделей: NVIDIA от 24 ГБ, удобно от 48 ГБ. Это своя карта или арендованный сервер.
  Писатель кода на 80B, Qwen3-Coder-Next, требует карту на 96 ГБ.

## Запуск

| Где | Установка | Команды |
| --- | --- | --- |
| Linux, macOS, WSL | `./install.sh`; с моделями на этой машине `./install.sh --models` | `./run.sh help` |
| Windows | двойной щелчок по `install.cmd` | `run.cmd help` |
| Арендованный сервер | `./run.sh box install` с вашего компьютера | `./run.sh box help` |

Дальше каждый день:

```
./run.sh add "Артём просыпается, а квартира затоплена"
./run.sh add --file рассказ.fb2          # по задаче на каждую часть
./run.sh run                             # или ./run.sh box run на сервере
./run.sh jobs                            # статусы и id
./run.sh storyboard ID                   # ключевые кадры на одном листе
./run.sh approve ID                      # ролик в outbox/
```

## Разработка

```
./install.sh
./run.sh test && ./run.sh lint
```

Код конвейера в `src/reelsmith/`, движок отрисовки в `runtime/`, сервис речи в
`services/speech/`, сверка с эталоном в `tools/reference_check.py`. Старый путь с диффузией
и ComfyUI лежит под меткой `shots-final`.
