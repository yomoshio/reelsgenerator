# reelsmith

Делает вертикальные ролики из одной строки-идеи. Пишет сценарий, озвучивает его, рисует
кадры, оживляет их, кладёт музыку и субтитры. Готовый ролик ждёт, пока человек его
посмотрит и одобрит. Всё работает на своих моделях, без облачных API: интернет нужен
только чтобы один раз скачать веса.

Идеей может быть одна фраза, например `Утром Артём просыпается, а квартира затоплена`,
или рассказ на 200 слов. Из неё выходит ролик на минуту с небольшим: плоская графика,
диктор, история с целью, препятствиями, новым персонажем и поворотом в конце, плашки с
целью и счётчиком, субтитры с выделенными словами. Из синопсиса сезона получается целая
серия выпусков со сквозными героями.

## Как это устроено

```
идея → план → сценарий → голос → кадры → клипы → музыка → сборка → вы одобряете
       Qwen3.5            VoxCPM2  Z-Image  Wan 2.2  ACE-Step  ffmpeg
                                            или наезд камеры
```

План выпуска нужен потому, что модель плохо придумывает связный сюжет, пока пишет шоты,
и почти дословно следует готовому плану. После кадров, клипов и сборки ролик смотрит
судья, та же Qwen3.5, но по картинкам.
Плохой клип переделывается сам. Как писать и как выглядеть, задаёт стиль, файл в
`styles/`. Каждый вызов модели записывается с ценой, поэтому видно, сколько стоит
годный ролик.

## Что нужно

- Видеокарта NVIDIA от 24 ГБ; удобно от 32 ГБ.
- 64 ГБ оперативной памяти и 250 ГБ на диске.
- Linux или Windows с WSL2, Docker с доступом к видеокарте.

## Запуск

```
make setup          # .env и папки
make build
make models         # около 90 ГБ весов
make llm-model
make voice DESC="A gripping storyteller in his forties, low warm voice, lively intonation, dramatic pauses, building tension, never monotone"
make up
make migrate
```

Дальше каждый день:

```
make add IDEA="Часть 2. Артём находит второй блокнот"
make jobs                     # статусы и id
make review ID=<id>           # ролик в review/
make approve ID=<id>          # готовый ролик в outbox/
```

Всё это можно делать и без терминала, в ComfyUI на http://localhost:8188: схема
«Новый ролик» принимает фразу или рассказ, «Новая серия» принимает синопсис, «Статус»
показывает ход работы, готовые ролики появляются в Ассетах. Подробно в
[comfyui.md](docs/comfyui.md). `make help` показывает все команды терминала.

## Разработка

Нужны Python 3.12 и ffmpeg, видеокарта не нужна.

```
python3.12 -m venv .venv && . .venv/bin/activate && pip install -e ".[dev]"
make test lint
make demo           # весь конвейер на заглушках
```

Код в `src/reelsmith/`, сервис голоса в `services/tts/`, скрипты в `scripts/`.
