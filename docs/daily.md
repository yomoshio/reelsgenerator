# Каждый день

## Идеи

```
./run.sh add "Артём просыпается, а квартира затоплена"
./run.sh add "длинный рассказ целиком..." --style blackout
./run.sh add --file studio/input/рассказ.fb2
```

От длины источника зависит, что с ним будет:
- **до 80 слов** — это идея, планировщик придумывает историю внутри стиля;
- **длиннее** — это рассказ, и его события сохраняются;
- **больше 1200 слов** — это рассказ или книга: текст пересказывается событиями и делится
  на эпизоды там, где поворачивает история. Каждый эпизод становится отдельной задачей, и
  для этого нужны модели.

Форматы файлов: `.txt`, `.md`, `.fb2`, `.epub`.

## Провести задачи

```
./run.sh run            # пока есть что делать
./run.sh run --once     # один проход по стадиям
./run.sh jobs           # id, статус, стиль, название, ошибка
./run.sh show ID        # журнал задачи: шаги, время, модели, что осталось неисправленным
```

## Посмотреть и решить

Готовый ролик лежит в `jobs/<id>/final.mp4`.

Перед ним можно посмотреть раскадровку: `./run.sh storyboard ID` кладёт средний кадр каждого
бита на один лист, `jobs/<id>/storyboard.jpg`.

| Решение | Команда |
| --- | --- |
| Годится | `./run.sh approve ID`: ролик и `post.txt` в `outbox/`. До трёх лучших сцен ролика уходят в примеры стиля, и кодер видит их в следующих роликах |
| Плох один бит | `./run.sh redo ID --beat 5 --note "банкомат должен стоять в магазине"`, потом `./run.sh run` |
| Плох голос | `./run.sh retry ID --status written`, потом `./run.sh run` |
| Плохо всё | `./run.sh reject ID --reason "..."`: причина остаётся в задаче |

Замечание из `redo` уходит кодеру вместе с задачей бита. Остальные биты не трогаются, ролик
собирается заново.

### Сверка с эталоном

`jobs/<id>/check.json` хранит 15 замеров против эталона «Блэкаут на 32 этаже»:
- длина ролика;
- число и длина сцен, переходы;
- яркость;
- движение;
- паузы в речи;
- громкость.

Проваленные замеры видны в `./run.sh show ID`. Они не мешают одобрить ролик, а только
подсказывают, на что смотреть.

## Сервер

```
./run.sh box run       # залить новые задачи и провести их на сервере
./run.sh box status    # задачи и загрузка видеокарты
./run.sh box logs      # ход конвейера
./run.sh box pull      # забрать задачи и голоса
```

Сторож из `box install` удалит сервер сам. Проверить, что он жив: `tail logs/autostop.log`.
Если он не запущен: `./run.sh box autostop`. Удалить сервер сразу, всё забрав:
`python3 scripts/autostop.py --now`.

## Голос

```
./run.sh voice "A calm low male voice in his thirties, close to the microphone" narrator
```

Голос делается по описанию на английском. В `voices/` появятся несколько дублей. Скопируйте
понравившийся поверх `narrator.wav` и `narrator.txt`. Стиль берёт голос с именем из своего
`[voice] name`.
