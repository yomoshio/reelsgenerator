# Сюжеты

Сюжет решает, досмотрят ли ролик. Здесь описано, как из идеи получается сценарий, откуда
брать идеи и как сравнивать, что придумала модель.

## Как идея становится сценарием

```
идея → план выпуска → сценарий по шотам
```

1. **Идея**: одна фраза, короткая история на 100–200 слов или уже готовый план.
2. **План выпуска** пишет модель по брифу стиля: герои с неизменной внешностью
   (лицо, волосы, одежда и обувь их эпохи: портрет рисуется с головы до ног, и без обуви
   герой выходит босым), 8–12 событий по порядку, деталь, заложенная в начале, и последняя
   фраза. Из фразы модель
   придумывает события сама, из истории извлекает их, сохраняя героев и порядок.
3. **Сценарий**: каждое событие раскладывается на шоты с репликой, кадром, движением и
   подачей голоса. Критик сверяет сценарий с планом.

Модель на 27 миллиардов плохо придумывает связный сюжет, пока пишет шоты, и почти
дословно следует готовому плану. Поэтому чем подробнее идея, тем точнее ролик.

## Что держит зрителя

Эти правила записаны в стиле `serial`, им следуют и мои планы в `studio/ideas/`:

- опасность в первой фразе, до имён и объяснений;
- цель названа во втором шоте и не меняется до её достижения;
- каждые два-три шота что-то меняется: новое препятствие, звук, счёт;
- счёт, который зритель слышит и видит на плашке: этажи, минуты, вдохи;
- препятствие решается конкретным действием, которое видно;
- новый персонаж с одной заметной деталью;
- последний шот возвращает эту деталь и переворачивает смысл, без пересказа.

## Библиотека структур

`studio/structures.toml` хранит куски сюжетов из книг в общественном достоянии: Уэллс,
Верн, Дефо, Джек Лондон, По, Шелли, Конан Дойл, Крейн, Бирс, Стокер, Гомер, Замятин,
Коннелл, Джекобс. Каждый кусок играет одну роль:

| Роль | Пример |
| --- | --- |
| мир | на станции пробита обшивка, воздух уходит по секции в час |
| герой | бортинженер Лида, никогда не была главной и боится решать за других |
| цель | добраться до шлюза, где стоит спасательная капсула |
| препятствие с приёмом | водоворот затягивает лодку, круглые бочки тонут медленнее, герой привязывает себя к бочке (По) |
| союзник с секретом | механик знает станцию наизусть, но молчит, почему один уцелел |
| поворот | побег удаётся слишком легко: его выпустили нарочно (Бирс) |
| финал | капсула рассчитана на двоих, а живых трое |

У каждого мира есть тема (space, zombie, survival, catastrophe, dystopia) и свой тег
(station, moon, train, hunt…). Куски, которые имеют смысл только в своём мире,
помечены его тегом, поэтому «стена» Замятина не попадёт на остров охотников.

```
./run.sh remix                       # 12 идей на все темы
./run.sh remix --theme space --count 6   # только космос
./run.sh remix --seed 2026             # та же затравка даёт те же идеи
```

Идеи лягут в `studio/ideas/remix-<затравка>.txt`, над каждой строкой указаны книги,
из которых она собрана. Свои куски добавляются в библиотеку: у каждого нужен источник из
списка `sources`, а проверка при загрузке скажет, если какому-то миру не хватает роли.

## Сравнить версии

В `studio/ideas/` лежат:

| Файл | Что это |
| --- | --- |
| `batch-01.txt` | десять коротких идей: космос, зомби, выживание, катастрофы, герой против мира |
| `batch-01-claude.md` | мои полные планы тех же десяти идей, чтобы прочитать |
| `batch-01-claude.txt` | те же планы строкой для очереди |
| `remix-2026.txt` | десять идей, собранных из библиотеки |

Сравнить планы, не тратя время на рендер:

```
./run.sh outline studio/ideas/batch-01.txt
```

Модель напишет свой план для каждой идеи в `studio/ideas/batch-01.outlines.md`, в том же
формате, что и мои. Сравнить готовые ролики: поставить обе пачки и посмотреть рядом.

```
./run.sh ideas studio/ideas/batch-01.txt
./run.sh ideas studio/ideas/batch-01-claude.txt
```

## Серии

Синопсис сезона превращается в серию командой `./run.sh series`, подробно в
[daily.md](daily.md#идеи). Сквозные герои получают одну внешность на весь сезон.
