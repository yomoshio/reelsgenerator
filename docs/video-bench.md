# Стенд видеомоделей

Папка `bench/` проверяет, как готовые видеомодели (LTX-2.5, MiniMax H3) делают серию по
раскадровке. Основной конвейер она не трогает: берёт у готовой задачи голос и время слов,
а картинку делает моделью.

## Что нужно

- Сервер с видеокартой от 32 ГБ и диском от 200 ГБ. Хост не должен брать деньги за трафик:
  веса весят около 110 ГБ, `scripts/rent.py` такие хосты пропускает.
- Токен Hugging Face с принятой лицензией LTX-2.5, на сервере в `/root/.hf-token`.

## Порядок

```bash
# на сервере, из папки проекта
bash bench/box.sh comfy            # ComfyUI на 127.0.0.1:8188
bash bench/box.sh weights h3 ltx   # веса

python3 bench/shots.py bench/tests/paw.json refs
python3 bench/run.py bench/tests/paw-refs.json --out bench/out/refs2      # листы героев, места, вещи
python3 bench/shots.py bench/tests/paw.json h3-r2v --refs refs2 --turbo
python3 bench/run.py bench/tests/paw-h3-r2v.json --out bench/out/episode  # по клипу на бит

# у себя, когда клипы скачаны
python bench/episode.py jobs/<задача> bench/out/episode --out outbox/серия.mp4 \
    --mute 2 4 --bed bench/out/episode/beat12.mp4
```

Раскадровка (`bench/tests/paw.json`) — это стиль одной строкой, герои с описанием и биты:
кто в кадре, что происходит, какие звуки. `bench/run.py` пишет в `results.jsonl` время и пик
видеопамяти каждого теста; тест с готовым файлом пропускается.

## Что показал прогон 28 ноября 2026

| Режим | Время на бит | Пик памяти | Итог |
|---|---|---|---|
| H3 по листам героев, 4 шага | 2–3,5 мин | 33 ГБ при ограничении, 45 без | герои и комната держатся, годится |
| H3 по листам героев, 20 шагов | 9–10 мин | 46 ГБ | на кадрах не лучше четырёх шагов |
| LTX-2.5 из текста | 1 мин | 32–41 ГБ | каждый бит в своём стиле, рисует мусорные подписи |
| LTX-2.5 от кадра H3 | 1 мин | 41 ГБ | уплывает в 3D, не годится |

- Лист героя и вещи рисуется на пустом фоне, иначе фон попадает в сцену, а модель вставляет
  сам лист как кадр.
- На просьбу «без речи» модель всё равно даёт героям бормотание: такие биты глушатся
  (`--mute`), под всю серию кладётся звук чистого клипа (`--bed`).
- Образ сервера без компилятора роняет кодировщик текста: `box.sh` ставит `build-essential`.
- Схемы в `bench/workflows` получены из шаблонов ComfyUI через `bench/export.py`.
