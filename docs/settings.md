# Настройки

Всё читается из `.env` и из переменных окружения с префиксом `REELSMITH_`. Пустая строка
значит значение по умолчанию.

## Где модели

| Строка | По умолчанию | Что это |
| --- | --- | --- |
| `REELSMITH_LLM_URL` | `http://localhost:11434/v1` | Языковые модели: любой сервер с OpenAI-совместимым API, ollama или vLLM |
| `REELSMITH_SPEECH_URL` | `http://localhost:8000` | Сервис речи |

## Кто что делает

| Строка | По умолчанию | Что это |
| --- | --- | --- |
| `REELSMITH_PLANNER` | `qwen3.5:27b` | Пишет план, рассказ и нарезку на биты |
| `REELSMITH_EDITOR` | пусто | Правит русский язык рассказа, например T-pro 2.0; пусто — без редактора |
| `REELSMITH_DIRECTOR` | `qwen3.5:27b` | Карточки героев и режиссура битов |
| `REELSMITH_CODER` | `qwen3-coder-next` | Пишет код сцен |
| `REELSMITH_VISION` | `qwen3.5:27b` | Смотрит ключевые кадры; нужна модель, которая видит картинки |
| `REELSMITH_TEMPERATURE` | `0.7` | Выше — смелее, ниже — строже |
| `REELSMITH_CODER_TEMPERATURE` | `0.3` | То же для кода сцен: коду нужна точность, а не выдумка |
| `REELSMITH_REASONING` | `none` | Рассуждения модели перед ответом: `none`, `low`, `medium`, `high`. С ними ответ идёт минуты вместо секунд; пусто — как решит сервер моделей |

## Что делаем

| Строка | По умолчанию | Что это |
| --- | --- | --- |
| `REELSMITH_STYLE` | `blackout` | Стиль по умолчанию для `add` |
| `REELSMITH_LANGUAGE` | `ru` | Язык роликов: ru, uk, be, en |
| `REELSMITH_REWRITES` | `2` | Сколько раз переписать историю или режиссуру, которые не прошли проверки |
| `REELSMITH_ROUNDS` | `4` | Сколько кругов дать коду сцены самое большее. Круги кончаются раньше, если замечания повторились. Остаётся лучшая сцена, которая рисуется; безопасная ставится, только если не нарисовалась ни одна |
| `REELSMITH_RETAKES` | `2` | Сколько раз перечитать бит, в котором диктор добавил слова |
| `REELSMITH_VARIANTS` | `1` | Сколько вариантов сцены кодер пишет в первом круге; остаётся тот, где меньше ошибок |
| `REELSMITH_TRIES` | `3` | Сколько упавших шагов до статуса `failed` |
| `REELSMITH_WORKERS` | `0` | Сколько ядер на отрисовку; 0 — все. Бит занимает около двух |
| `REELSMITH_MIN_FREE_GB` | `2` | Меньше этого места на диске — отрисовка не начнётся |

## Пути

`REELSMITH_JOBS` (`jobs`), `REELSMITH_STYLES` (`styles`), `REELSMITH_LIBRARY`
(`library/things`), `REELSMITH_OUTBOX` (`outbox`), `REELSMITH_RUNTIME` (`runtime`).

## Сервер

`SERVER_HOST`, `SERVER_PORT`, `SERVER_KEY`, `SERVER_DIR` (`/root/reelsmith`) и
`VAST_INSTANCE` нужны командам `./run.sh box` и сторожу, см. [setup.md](setup.md).

Две настройки ollama на сервере:
- `OLLAMA_MAX_LOADED_MODELS` (`2`): сколько моделей держать в памяти сразу. Кодер и зрение
  чередуются на каждом бите, поэтому на большой карте их стоит держать вместе.
- `OLLAMA_CONTEXT_LENGTH` (`32768`).
