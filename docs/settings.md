# Настройки

Все настройки лежат в `.env` в папке проекта. Пустая строка или отсутствующая строка
значат значение по умолчанию. После правки выполните `make up`: изменившиеся контейнеры
перезапустятся сами. Образец со всеми строками и пояснениями лежит в `.env.example`.

## Что делаем

| Переменная | По умолчанию | Что меняет |
| --- | --- | --- |
| `REELSMITH_STYLE` | noir; в `.env.example` стоит serial | стиль новых задач, см. [styles.md](styles.md) |
| `REELSMITH_LANGUAGE` | ru | язык реплик и субтитров |
| `REELSMITH_VOICE` | narrator | голос диктора: `voices/<имя>.wav` и `.txt` |
| `REELSMITH_IMAGE_MODEL` | z-image | чем рисовать кадры |
| `REELSMITH_VIDEO_MODEL` | wan-2.2; в `.env.example` стоит still | чем оживлять: `still` это медленный наезд камеры без нейросети, не плывёт и считается за секунды; `wan-2.2` настоящая анимация, около минуты на клип; `wan-5b`, если есть `workflows/animate-draft.json` |
| `REELSMITH_CALM_VIDEO_MODEL` | пусто; в `.env.example` стоит still | модель для шотов, где писатель отметил, что ничего не движется; пусто значит та же, что `VIDEO_MODEL` |
| `REELSMITH_HOOK_VIDEO_MODEL` | пусто | модель для первых шотов-хука, кто бы в них ни двигался; пусто значит по общему правилу |
| `REELSMITH_CAST_IMAGE_MODEL` | пусто | `qwen-edit` включает одинаковых героев: для каждого рисуется портрет, кадры с ним рисуются по портрету; нужны веса `make models ONLY=character OPTIONAL=1` |
| `REELSMITH_HOOK_SHOTS` | 2 | сколько первых шотов считать хуком |
| `REELSMITH_GPU_HOUR_USD` | 0.99 | цена часа карты; отчёт переводит GPU-время в деньги |

Стиль и модели можно задать и для одной задачи: `make add IDEA="..." STYLE=noir`.

## Языковая модель

| Переменная | По умолчанию | Что меняет |
| --- | --- | --- |
| `REELSMITH_WRITER_MODEL` | qwen3.5:27b | модель Ollama для сценария и критика; после смены `make llm-model` |
| `REELSMITH_JUDGE_MODEL` | qwen3.5:27b | модель судьи; должна понимать картинки |
| `REELSMITH_WRITER_TEMPERATURE` | 0.8 | выше значит смелее и разнообразнее сценарии, ниже значит ровнее |
| `REELSMITH_CRITIC_TEMPERATURE` | 0.2 | разброс оценок критика |
| `REELSMITH_JUDGE_TEMPERATURE` | 0.1 | разброс оценок судьи по картинкам |
| `REELSMITH_JUDGE_WIDTH` | 540 | ширина стоп-кадров для судьи; клипы 480 в ширину, шире смысла нет, пока не подняты клипы |
| `REELSMITH_LLM_CONTEXT` | 12288 | контекст модели в токенах; для `JUDGE_WIDTH=1080` нужно около 32768, это больше видеопамяти и медленнее |

## Кадры, клипы, музыка, голос

Время указано для RTX 4090 48 ГБ.

| Переменная | По умолчанию | Что меняет |
| --- | --- | --- |
| `REELSMITH_FRAME_WIDTH`, `_HEIGHT` | 720, 1280 | размер кадра, кратный 16; кадр около 4 с |
| `REELSMITH_FRAME_STEPS` | 8 | шаги Z-Image Turbo; модель рассчитана на 8 |
| `REELSMITH_EDIT_STEPS` | 20 | шаги Qwen-Image-Edit для кадров по портрету; оценка около 20 секунд на кадр |
| `REELSMITH_CLIP_WIDTH`, `_HEIGHT` | 480, 848 | размер клипа, кратный 16; 720 × 1280 чётче и примерно в 2,5 раза дольше |
| `REELSMITH_CLIP_STEPS` | 4 | шаги Wan, делятся пополам между двумя его моделями; 6 или 8 дают меньше артефактов и в 1,5–2 раза дольше |
| `REELSMITH_CLIP_SECONDS` | 5 | самый длинный клип; если реплика длиннее, последний кадр держится |
| `REELSMITH_MUSIC_STEPS` | 8 | шаги ACE-Step |
| `REELSMITH_MUSIC_LEVEL` | 0.22 | громкость музыки под голосом, от 0 до 1 |
| `REELSMITH_VOICE_CFG` | 2.0 | выше значит ближе к эталонному голосу и суше |
| `REELSMITH_VOICE_STEPS` | 10 | больше значит чище и дольше |

Клип на 4–5 секунд при значениях по умолчанию считается около минуты, и это основная часть
времени ролика.

## Наборы: черновик и качество

`.env.example` настроен на качество: так он и копируется в `.env`. Черновик нужен, чтобы
быстро проверить сюжет и плашки, его строки заменяют одноимённые в `.env`. Время указано
для ролика на 25 шотов на RTX 4090 48 ГБ, если судья ничего не бракует, и это оценка, а
не замер.

| Строка | Черновик | Качество, в `.env.example` |
| --- | --- | --- |
| `REELSMITH_VIDEO_MODEL` | still | wan-2.2 |
| `REELSMITH_CALM_VIDEO_MODEL` | still | пусто, Wan оживляет все шоты |
| `REELSMITH_FRAME_WIDTH`, `_HEIGHT` | 720, 1280 | 1088, 1920 |
| `REELSMITH_CLIP_WIDTH`, `_HEIGHT` | 480, 848 | 720, 1280 |
| `REELSMITH_CLIP_STEPS` | 4 | 8 |
| `REELSMITH_CAST_IMAGE_MODEL` | пусто | пусто, qwen-edit по желанию |
| `REELSMITH_CANDIDATES` | 1 | 3 |
| `REELSMITH_REWRITES` | 1 | 3 |
| `REELSMITH_VOICE_STEPS` | 10 | 20 |
| `REELSMITH_JUDGE_WIDTH` | 540 | 720 |
| `REELSMITH_LLM_CONTEXT` | 12288 | 16384 |
| `REELSMITH_QA_PASS` | 0 | 0 |
| Время ролика, оценка | около 10 минут | полтора-два часа |

Самое заметное в качестве дают клипы 720 × 1280 и Wan на всех шотах: клипы перестают
быть мягкими после растягивания до 1080 × 1920, а ролик становится мультфильмом, а не
набором кадров. Ещё выше качество даёт `REELSMITH_CAST_IMAGE_MODEL=qwen-edit`: герои
рисуются по портрету и не меняются от кадра к кадру. В `.env.example` он выключен, потому
что ему нужны ещё около 30 ГБ весов: `make models ONLY=character OPTIONAL=1`. В отдельной
ветке лежит `wan-2.2-hd`, он увеличивает клипы до 1080 × 1920 нейросетью. Итоговая оценка
ролика в обоих наборах только записывается: судья по целому ролику пока бракует почти всё.

Сюжет больше всего зависит от модели писателя, `REELSMITH_WRITER_MODEL`. Если на карте
есть место, модель крупнее даст связнее планы. Сравнивать модели честнее всего на одной и
той же пачке идей.

## Проверки качества

| Переменная | По умолчанию | Что меняет |
| --- | --- | --- |
| `REELSMITH_SCRIPT_PASS` | 7 | оценка критика, с которой сценарий идёт дальше без переписывания |
| `REELSMITH_CLIP_PASS` | 6 | оценка судьи, ниже которой клип переделывается |
| `REELSMITH_QA_PASS` | 7 | оценка готового ролика, ниже которой плохие шоты переделываются |
| `REELSMITH_REWRITES` | 2 | сколько раз переписать сценарий |
| `REELSMITH_CANDIDATES` | 2 | сколько кадров рисовать на шот, судья выбирает один |
| `REELSMITH_CLIP_TRIES` | 3 | сколько раз переделать клип, прежде чем оставить как есть |
| `REELSMITH_MAX_ATTEMPTS` | 5 | сколько неудач и переделок, прежде чем задача станет `failed` |

Ниже порог значит меньше переделок, быстрее и больше брака. Если судья бракует почти всё,
сначала посмотрите на клипы сами: чаще виновато резкое движение в сценарии, а не порог.
