# Установка

Конвейер ставится на ваш компьютер, модели — туда, где есть видеокарта. Это может быть
тот же компьютер или арендованный сервер.

## Этот компьютер: конвейер

```
./install.sh
```

Скрипт ставит:
- ffmpeg;
- Node 22, если его нет;
- зависимости движка (`npm ci` в `runtime/`);
- Python-окружение `.venv`;
- `.env` из `.env.example`.

Видеокарта для этого не нужна. Проверка: `./run.sh test`.

## Модели на своей видеокарте

```
./install.sh --models
```

Нужны NVIDIA от 24 ГБ, Docker и около 100 ГБ на диске. Скрипт делает следующее:
- ставит Docker и доступ к видеокарте, если их нет;
- собирает сервис речи и запускает его вместе с ollama;
- скачивает языковые модели, названные в `.env`;
- делает голос диктора;
- в конце запускает `./run.sh smoke`: по одному вызову каждой модели и один кадр движка.

На чистой Ubuntu без драйвера сначала `./install.sh driver`, перезагрузка, потом снова
`./install.sh --models`.

## Арендованный сервер на vast.ai

Нужна виртуальная машина: в обычном инстансе Docker не поднимется. Выберите шаблон
«Ubuntu 22.04 VM».

| Поле | Значение |
| --- | --- |
| GPU | одна карта на 96 ГБ (RTX PRO 6000) для Qwen3-Coder-Next, или на 48 ГБ для кодера на 30B |
| Min CUDA Version | 12.8 |
| Disk | от 150 ГБ |
| CPU RAM | от 64 ГБ |
| Internet Download | от 500 Мбит/с |

Впишите в `.env` адрес из карточки аренды и номер инстанса:

```
SERVER_HOST=root@203.0.113.10
SERVER_PORT=41377
SERVER_KEY=~/.ssh/id_ed25519_vast
VAST_INSTANCE=60216718
```

Затем:

```
python3 scripts/autostop.py --set-key   # один раз: ключ API с cloud.vast.ai/manage-keys
./run.sh box install
```

`box install` делает три вещи в таком порядке:
1. Заливает код, `.env` и голоса.
2. Запускает на этом компьютере сторожа, ещё до установки.
3. Ставит на сервере конвейер и модели.

Сторож удаляет сервер, когда:
- все задачи закончены;
- сервер простоял без работы `--idle-minutes`, по умолчанию 60 минут;
- баланса осталось меньше чем на час.

Перед удалением он забирает папки задач и голоса и проверяет, что каждый готовый ролик
приехал целиком. Ход его работы — в `logs/autostop.log`.

Остановленный инстанс vast продолжает списывать деньги за диск, поэтому сервер удаляется,
а не останавливается.

### Где идёт конвейер

- **На сервере** (рекомендую): `./run.sh box run`. Задачи заливаются на сервер, конвейер
  работает там на всех его ядрах. `./run.sh box pull` забирает результат.
- **Здесь, модели на сервере**: `./run.sh box tunnel` в отдельном окне, потом
  `./run.sh run` здесь. Окно туннеля должно оставаться открытым.

## Windows

Двойной щелчок по `install.cmd`. Он ставит WSL с Ubuntu и Docker Desktop, копирует проект в
Ubuntu и запускает там `install.sh --models`. На рабочем столе появятся ярлыки: запустить,
остановить, ролики, статус. Команды те же, только через `run.cmd`.

## Проверка

```
./run.sh smoke
```

Показывает время каждого вызова: планировщик, кодер, зрение, речь и один кадр движка.
Строка `FAILED` называет причину. Чаще всего это недоступный сервер или не скачанная
модель.
