# Граф в ComfyUI

Пайплайн можно собирать и запускать в ComfyUI: идея превращается в задание, а каждая стадия
— отдельный узел. Узлы ничего не считают сами: они вызывают тот же код, что и `./run.sh`,
и пишут в ту же папку `jobs/`.

## Установка

Нужен ComfyUI на Python 3.12 или новее. Модели ComfyUI не нужны: узлы обращаются к ollama и
сервисам речи по адресам из `.env`.

```bash
ln -s /путь/к/reelsmith/comfyui/reelsmith_nodes /путь/к/ComfyUI/custom_nodes/reelsmith_nodes
/путь/к/ComfyUI/venv/bin/pip install -e /путь/к/reelsmith
```

Перезапустите ComfyUI. Узлы лежат в разделе `reelsmith`. Если папка reelsmith переехала,
задайте её в переменной `REELSMITH_ROOT` или в поле `root` узла настроек.

## Узлы

| Узел | Что делает |
|---|---|
| идея | Текст идеи и стиль. Даёт задание; та же идея в том же стиле — то же задание, копий не будет |
| настройки | Кто читает (`chatterbox`, `qwen`), как ставятся сцены (`sheet`, `coder`), адреса и модели. Пустое поле берётся из `.env` |
| сценарий | План, биты, карточки персонажей, постановка |
| голос | Диктор читает биты, слова получают время |
| постановка | Анкета или код сцены на каждый бит, ключевые кадры |
| рендер | Кадры, музыка, `final.mp4` |
| ролик целиком | Все стадии одним узлом |
| просмотр | Показывает ролик; пока его нет — средний кадр каждого бита. Отдаёт путь к ролику и текст по битам |

## Как собрать граф

Самый короткий: `идея → ролик целиком → просмотр`.

По стадиям: `идея → сценарий → голос → постановка → рендер → просмотр`. Узел `настройки`
подключается к тем стадиям, для которых вы что-то меняете. Узел `просмотр` можно поставить
после постановки, чтобы увидеть кадры до рендера.

## Что пересчитывается

Стадия, уже сделанная с теми же настройками, пропускается. Если её настройки изменились,
она и всё после неё делается заново: сменили голос — перечитывается голос, заново ставятся
сцены и идёт рендер, а сценарий остаётся. Что именно читает каждая стадия, записано в
`READS` в `src/reelsmith/graph.py`; отметки о сделанном лежат в `graph.json` в папке задания.

Ошибка стадии показывается на узле с причиной. После исправления причины запустите граф
снова: стадия начнётся с того же места.
