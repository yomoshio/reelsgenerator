# Стили

Стиль — это папка `styles/<имя>/`. В ней `style.toml` и файлы, которые он называет:
музыка, фон, звуки плашек, примеры сцен. Ролики одного стиля выглядят как одна серия,
другой стиль — это другая папка.

```
styles/blackout/
  style.toml
  examples/*.js         две сцены канала, по ним кодер видит, как писать
  music.flac            музыка под всем роликом (необязательно)
  drone.wav             фон под голосом каждого бита (необязательно)
  sfx/<вид плашки>.wav  звук, с которым появляется плашка: sfx/stamp.wav, sfx/rule_card.wav
```

Чего нет в папке, того в ролике просто нет: без `music.flac` ролик идёт без музыки.
Пока у стиля нет своих записей, фон и звуки плашек можно сделать из тонов и шума:
`.venv/bin/python scripts/make_sounds.py styles/<имя>`. Файлы `.wav` и `.flac` стилей в git не
попадают.

## Поля `style.toml`

| Поле | Что это |
| --- | --- |
| `about` | Одна строка о канале |
| `music`, `bed` | Имена файлов музыки и фона в папке стиля |
| `director` | Бриф режиссёру и кодеру: как выглядят сцены канала, какие приёмы уместны |
| `[story] brief` | Бриф планировщику: структура эпизода, голос рассказчика, чего избегать |
| `[story] seconds` | Длина ролика, от и до |
| `[story] beats` | Сколько битов в эпизоде |
| `[story] words` | Больше скольких слов не бывает в реплике |
| `[story] rules` | Сколько карточек правил; `[0, 0]` — канал без правил |
| `[palette]` | Цвета движка, все обязательны: `night`, `wall`, `floor`, `line`, `light`, `ink`, `neutral`, `threat`, `key`, `solved`; можно добавить `wood`, `steel`, `water`, `warm` |
| `[fonts] plate` | Файл шрифта плашек: в папке стиля или в `runtime/fonts/` |
| `[fonts] caption` | Имя шрифта субтитров |
| `[captions]` | Размер, отступ снизу, слов в строке, цвета сказанного, текущего и будущего слова, обводка |
| `[voice]` | `name` — голос в `voices/`, `about` — описание голоса для `./run.sh voice` |

## Как сделать свой

1. Скопируйте `styles/blackout` в `styles/<имя>`.
2. Перепишите `about`, `[story] brief` и `director` под свой канал. Палитру меняйте целиком:
   стены, пол и свет задают настроение каждой сцены.
3. Положите две свои сцены в `examples/`. Пример лучше брифа: кодер повторяет то, что видит.
4. `./run.sh styles` покажет новый стиль. `./run.sh add "идея" --style <имя>` возьмёт его.

## Чего стиль не может

Стиль не добавляет новые вещи, места и позы. Их рисует движок, см.
[runtime.md](runtime.md). Новые вещи кладутся в библиотеку `library/things/` как SVG.
